## OpenCode 플러그인 경고 수정 패턴 - 기능 구현 및 버전 핀 고정

OpenCode 빌드에서 발생하는 두 가지 공통 경고와 수정 방법.

**경고 1: 플러그인 스텁이 주석 처리됨**
- 원인: convert-hooks-to-plugins.py가 commented-out 코드 생성
- 수정: generate_script_exec() 함수로 실제 동작 코드 생성
  - tool.execute.before: TOOL_NAME/TOOL_INPUT env vars + exitCode 체크 + throw
  - 기타 이벤트: .nothrow() (비차단)
- 파일: scripts/convert-hooks-to-plugins.py

**경고 2: @opencode-ai/plugin "latest" 버전 핀 미고정**
- 원인: build-opencode.sh의 package.json 생성 시 "latest" 사용
- 수정: npm view @opencode-ai/plugin version 으로 현재 버전 확인 후 ^x.y.z 형식으로 고정
- 현재 버전: 1.2.10 → "^1.2.10"
- 파일: scripts/build-opencode.sh line ~455

**검증:**
make build-opencode 실행 후 WARN 없이 BUILD SUCCESSFUL 확인.
