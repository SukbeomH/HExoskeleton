## bulk sed로 디렉토리 경로 참조 일괄 치환하는 패턴

대규모 디렉토리 rename 시 경로 참조를 일괄 치환하는 검증된 패턴.

단계:
1. 영향 범위 파악: grep -rl '\.gsd' . --include='*.md' --include='*.sh' 등
2. 보존 대상 식별: CHANGELOG(역사), 빌드 아티팩트, 메모리/archive(런타임 데이터)
3. 1차 bulk sed: find + -exec sed -i '' 's/\.gsd\//..hxsk\//g; s/\.gsd\b/.hxsk/g' {} \;
4. 잔여 확인: grep -rl 재실행 → 누락 파일 개별 처리
5. .gitignore/settings.json 별도 처리 (특수 패턴)
6. 디렉토리 rename: mv .gsd .hxsk
7. git 스테이징: git add .hxsk/ && git rm -r --cached .gsd/ && git add -u
   → git이 rename으로 감지 (similarity 89%+)

주의사항:
- sed 패턴에서 .gsd 단독(trailing 없음) 케이스 별도 처리 필요: s/\.gsd/.hxsk/g
- 심볼릭 링크(scripts/md-*.sh → .claude/hooks/)는 영향 없음
- macOS sed: -i '' (빈 문자열 필수), Linux: -i만 사용
