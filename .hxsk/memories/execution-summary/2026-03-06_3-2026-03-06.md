## 빌드 타겟 훅 이식 분석 — 3개 타겟 문제점 발굴 (2026-03-06)

hxsk-plugin, antigravity-boilerplate, opencode-boilerplate 빌드 후 훅 이식 현황 분석.

hxsk-plugin: hooks/hooks.json 경로 Claude Code Plugin 스펙 미검증(P1 HIGH). verify_count Scripts 기대값 9 오류(P2).
antigravity: bash-guard/file-protect 보안 훅 대체 없음(A1 HIGH). 세션 메모리 자동저장 미작동(A2 HIGH). IDE 훅 지원 여부 불명(A3).
opencode: TS 스텁이 bash 미실행(O1 HIGH). npm install 누락(O2 HIGH). SubagentStop 매핑 없음(O3). Stop→session.idle 매핑 불확실(O4).

antigravity는 의도적으로 훅 없이 rules로 대체하는 설계이나 보안 훅 공백이 문제.
opencode는 TS 플러그인 생성은 하지만 실제 동작 코드가 없어 껍데기 상태.
